# DimLife Радио

Нативное Android-приложение интернет-радио в фирменном тёмном стиле DimLife с неоново-зелёными акцентами.

## Что уже реализовано
- Каталог популярных интернет-радиостанций через Radio Browser.
- Поиск по названию станции.
- Воспроизведение потоков через Android Media3 / ExoPlayer.
- Избранное с локальным сохранением.
- Добавление собственных станций по прямой HTTP(S)-ссылке на поток.
- Поделиться ссылкой на текущую станцию.
- Адаптивный интерфейс для телефона.

## Сборка APK
Каждый push в `main` запускает GitHub Actions. APK публикуется как артефакт `DimLife-Radio-APK` и прикрепляется к предварительному релизу.

- [Сборки и артефакты](https://github.com/dimliferu/DimLifeRadio/actions)
- [Релизы APK](https://github.com/dimliferu/DimLifeRadio/releases)

## Технические детали
- Kotlin
- Jetpack Compose + Material 3
- Android Media3 ExoPlayer
- Min SDK 24
- Java 17 / Gradle 8.9

Список пользовательских станций и избранное сохраняются локально на устройстве. Будущую собственную станцию DimLife можно будет добавить как обычный поток после запуска вещания.
